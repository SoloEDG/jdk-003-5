# 余烬行旅

安装依赖：`npm install`

本地启动：`npm run dev`，打开终端显示的地址。

类型检查：`npm run typecheck`

逻辑测试：`npm test`（同伴系统的单元流与端到端命令流，通过 esbuild 在 Node 中运行）

Docker 启动：`docker compose -p pinru-jdk003-high-1113 up --build -d`，访问 http://localhost:18023。

停止：`docker compose -p pinru-jdk003-high-1113 down`。

## 同伴系统

- 路线上的「招募」节点可邀请同伴入队。每名同伴拥有独立生命、状态与专属牌；
  入队后专属牌进入战斗抽牌池，全队共用能量，但出牌效果（伤害/格挡/力量/治疗等）
  归属于出牌的那名角色。
- 同伴倒下后本场不能行动，其手牌与各牌堆中的专属牌立即移入消耗；倒下状态在战后
  保留，不会自动复活，必须在篝火节点支付金币救治。
- 战斗胜利的奖励可选择同伴成长（生命训练 / 凝神演练强化专属牌 / 获得稀有专属牌），
  成长进入待领取队列。
- 商店向在队同伴出售专属补给与稀有专属牌；已购买未领取的补给记录已付费用。
- 牌组页每张牌标注所属者，并展示同伴离队时会带走的专属牌、待领取成长与补给。
- 同伴中途离队时：先从出战牌堆移除其全部专属牌，再解除待领取成长引用，
  已付费未领取的补给按原价退还；离队同伴不会再出现在战斗牌堆中，也不与他人共享生命。
